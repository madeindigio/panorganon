Panorganon, quiero que sea un servidor MCP hecho en golang, quiero que añadas comandos por command line usando una librería ampliamente usada, con argumentos como --config fichero_config.yaml y --version indicando la versión que deberá usarse la tag de compilación y commit de la versióon actual en tiempo de compilación.
Este servidor MCP debe implementar con la librería go-mcp soporte para stdio y streamable-http, se debe de configurar en el fichero yaml el puerto y endpoint a escuchar en la versión streamable-http. También debe de generar logs en fichero, se deberá poder configurar tanto en cli arguments como en el fichero yaml.
Este servidor debe actuar como servidor de búsqueda y catálogo de otros servidores MCP. Quiero que en el fichero de configuración yaml permita configurar tanto servidores stdio como servidores streamable-http y sse. El objetivo es que un cliente mcp sólo tenga que configurar el servidor mcp de Panorganon y éste dará acceso a todas las demás tools.
No será un MCP Gateway al uso, sino que dispondrá de una tool para buscar las tools a partir de un prompt o texto para hacer una tarea, y devolver las tools por nombre apropiadas, junto a cómo deben de usarse (los argumentos y descripción de estas tools), para llamar a estas tools no se hará directamente por nombre, sino llamando a la tool de panorganon de exec_tool, indicando el nombre y los parámetros que se deben de usar.
Panorganon debe de poder llamar en tiempo real a la tool del servidor mcp apropiado que tenga en configuración. Es deseable que los servidores, sobre todo stdio, no estén ejecutándose todo el tiempo, sino sólamente cuando se necesite ser llamado, salvo que un parámetro en la configuración se indique keepalive:true para que se mantenga ejecutado siempre en segundo plano. Lo mismo se podría hacer con los servidores http y sse.

Quiero que uses la funcionalidad de sampling de los servidores mcp para poder llamar al modelo indicando las tools o descripciones de las tools disponibles, para que haga la selección sobre una tarea, de las tools apropiadas para la misma, ese texto e instrucciones deberá estar redactado en inglés.

Panorganon podría ejecutar los servidores mcp al inicio para obtener todas las descripciones e información de las tools, y almacenarlas en una bbdd interna basada en rqlite https://github.com/rqlite/rqlite para no tener que leerlas siempre
